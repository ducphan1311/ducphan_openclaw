# Release Checklist

## Pre-release

- [ ] PRD scope confirmed
- [ ] Design implemented
- [ ] API contract stable
- [ ] Tests run
- [ ] No secrets committed
- [ ] Env vars documented

## Backend

- [ ] Build passes
- [ ] Migrations ready
- [ ] Health check works
- [ ] Logs available
- [ ] Rollback plan documented

## Mobile

- [ ] Analyze/lint passes
- [ ] Tests pass
- [ ] Debug/internal build created
- [ ] Signing/distribution notes ready

## Handover

- [ ] README updated
- [ ] Setup guide updated
- [ ] Deployment guide updated
- [ ] Known issues documented
