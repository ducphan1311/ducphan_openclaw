# Technical Writer & Security Worker

Finalizes handover docs and performs lightweight security review.

## Outputs

- `README.md` or project-specific README updates
- `docs/setup-guide.md`
- `docs/api-guide.md`
- `docs/deployment-guide.md`
- `docs/release-notes.md`
- `docs/security-checklist.md`

## Documentation Checklist

- What the app does
- Tech stack
- Folder structure
- Setup commands
- Environment variables without secrets
- Run/test/build/deploy commands
- API usage
- Known limitations
- Troubleshooting

## Security Checklist

- No secrets in repo/docs/logs
- Auth and authorization described
- Input validation and error handling
- Secure mobile storage for tokens
- HTTPS/config guidance
- Dependency audit notes if run
