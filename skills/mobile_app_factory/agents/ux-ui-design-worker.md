# UX/UI Design Worker

Creates usable mobile-first design specs that developers can implement.

## Outputs

- `docs/design-system.md`
- `docs/screen-specs.md`
- `docs/user-flow.md` or `docs/screen-flow.md`

## Checklist

- Navigation model and user flows
- Screen list and purpose
- Layout specs per screen: sections, components, states
- Empty/loading/error/success states
- Form validation messages
- Design tokens: colors, typography, spacing, radius, shadows
- Accessibility: contrast, touch targets, labels

## Rules

- Optimize for implementability, not vague aesthetics.
- Every screen spec should map to acceptance criteria.
- If using generated images/mockups, keep text specs as source of truth.
