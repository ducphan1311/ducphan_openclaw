# Category Checklists

Load this only when product-specific validation matters.

## Shoes / Sneakers

Inputs:
- Size in EU/US/UK/CM, foot width if known.
- Use: daily, running, gym, office, fashion, date, rain.
- Style/color preference.
- Authentic-only or acceptable alternatives.
- New/used tolerance.

Checks:
- Official size chart and return/exchange policy.
- Seller authenticity: official mall/shop, authorized retailer, invoice/tag/box claims.
- Price vs common market price; extreme discount may indicate fake/old stock.
- Photos: outsole, tag/label, box code, stitching, logo, material texture.
- Availability in exact size/color.
- Comfort notes from multiple reviews, not just star rating.

Ranking preference:
1. Correct size + reliable seller beats small price savings.
2. Authenticity and return policy matter more for expensive branded shoes.
3. For daily wear, comfort/durability beats hype.

## Clothing

Checks:
- Size chart, material, fit photos, washing/shrink notes.
- Return policy for wrong size.
- Real customer photos if marketplace.
- Color accuracy risk.

## Electronics

Checks:
- Exact model/SKU/region version.
- Warranty: official vs shop warranty.
- New/open-box/refurb/used condition.
- Included accessories and charger compatibility.
- Return policy and invoice/VAT if needed.
- Firmware/network compatibility for phones/wearables.

## Household / Furniture

Checks:
- Dimensions, load capacity, material, assembly.
- Delivery fee and installation.
- Return difficulty and damage policy.
- Real customer photos for color/material.

## Gifts

Checks:
- Delivery deadline.
- Packaging/gift wrap.
- Recipient preferences and avoid-list.
- Return/exchange if size/style sensitive.
