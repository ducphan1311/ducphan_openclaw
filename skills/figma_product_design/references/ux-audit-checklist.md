# UX Audit Checklist

## Clarity
- Is the primary action obvious?
- Does each screen have one clear purpose?
- Are labels specific and user-facing?
- Are error states actionable?

## Accessibility
- Text contrast target: WCAG AA.
- Touch targets: 44x44 pt minimum.
- Avoid relying on color alone.
- Inputs need labels, helper text, validation.

## Hierarchy
- Clear title/subtitle/action hierarchy.
- Important content above fold.
- Secondary actions visually secondary.

## Consistency
- Same component behaves the same everywhere.
- Same spacing scale across frames.
- Same typography roles across frames.

## Mobile responsiveness
- Safe area respected.
- Keyboard/input state considered.
- Long content scrolls naturally.
- Empty/loading/error states included.

## Design-to-code
- Tokens are named.
- Components are reusable.
- Layout can be expressed in Flutter/React Native.
- No impossible blur/layering unless intentionally supported.
